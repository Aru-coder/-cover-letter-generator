# AI Cover Letter Generator

A responsive Cover Letter Generator application built using HTML, CSS, and JavaScript.

This project was developed for the Prodesk IT Sprint 04 assignment and demonstrates form handling, DOM manipulation, dynamic content generation, state management, and modern UI development.

## Features

* Generate ATS-friendly cover letters
* Dynamic form handling
* Character counter for skills input
* Word count for generated letters
* Loading state while generating content
* Copy to Clipboard functionality
* Download cover letter as TXT file
* Regenerate cover letter
* Resume upload interface
* Dark Mode support
* Responsive design
